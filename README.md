# 高速公路交通流分析与拥堵预测

基于真实高速公路检测数据，训练一个"输入条件 → 拥堵概率"的整体规律模型，并把它用在两个场景里：

1. **预测展示页**：看不同时段、天气、日期类型、车道数下的流量、车速、占有率和拥堵概率；
2. **警力调度演示**：把预测结果落到 86 个具体断面上，做实时路况判断、自动派警、设备故障诊断和历史回看。

> 核心理念：导航告诉你"现在堵不堵"，本项目回答"未来什么时间、什么条件下大概率会堵"。

## 数据说明

| 数据 | 位置 | 规模 |
| --- | --- | --- |
| 训练数据（清洗后） | `07_成果展示/03_数据/清洗后数据.csv` | 652,384 条，86 个断面，2018-11 ~ 2020-05 |
| 原始真实数据 | `01_原始数据/波特兰高速_真实数据_多冬季.csv` | 与训练数据同源，含道路、方向等原始字段 |
| 合成传感器数据 | `01_原始数据/高速公路交通流传感器数据集.csv` | 28,000 条，按 PeMS 流量-速度-占有率关系合成，用于早期原型 |

训练数据字段：时间戳、断面编号、小时、是否周末/节假日、流量、平均车速、占有率、车道数、天气、温度、降水、降雪。

## 模型

- 算法：随机森林分类 + 等温回归校准（isotonic），另外用随机森林回归输出流量、车速、占有率。
- 输入：`hour_of_day`、`wx`（6 级天气）、`day_type`（工作日/周末/节假日）、`lane_count`。
- 拥堵定义：车速 < 70 km/h。
- 评估：AUC 0.826，Brier 0.078，基准拥堵率 10.7%。
- 输出：导出的 1728 种组合（24 时段 × 6 天气 × 3 日期类型 × 4 车道档），网页直接查表。

模型文件 `*.pkl` 体积较大（80–135MB），未纳入仓库，可用训练脚本重新生成：

```bash
cd 07_成果展示/04_模型代码
python3 整体规律模型.py
```

默认读取 `../03_数据/清洗后数据.csv`，输出 `models/整体规律模型.pkl` 和 `../01_网页系统/prediction_data.js`。

## 运行

安装依赖：

```bash
pip install -r 07_成果展示/requirements.txt
```

### 1. 预测展示页

```bash
cd 07_成果展示/01_网页系统
python3 服务.py
```

打开 http://localhost:8000 。页面上的图表直接读同目录的 `prediction_data.js`，不访问外网；只有"导入 CSV 重新训练"会调用本地服务。

### 2. 警力调度演示

```bash
cd 09_警力调度演示
python3 服务.py
```

打开 http://127.0.0.1:8766 。包含：

- 实时路况判断（基于同一套预测网格 + 断面历史基线）；
- 均衡覆盖派警：先保证每个拥堵段有人，警力不足时一名警员负责一整段连续断面（最多 8 个）；
- 预置待命：富余警力提前到 1 小时后可能拥堵的位置；
- 手动改派：地图上点警员指定新位置，只补空位、不推翻已有任务；
- 设备故障诊断：数据冻结、速度掉零、数值尖峰、占有率漂移四类；
- 历史回看：任务跑满一天后可拖进度条查看任意时刻。

详细说明见 `09_警力调度演示/项目说明.md`。

## 说明

- 警力调度是演示系统，警力编制、派警规则、处置时长均为设定值，路网为示意图。
- 演示中的设备故障为按计划注入，用于展示诊断流程。
- 预测结果来自历史数据训练，遇到极端天气、临时管制等情况可能偏离实际。
