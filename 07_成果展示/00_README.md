# 高速公路拥堵预测系统 · 完整源码包

这是一个可以自己跑、自己改的完整项目。网页、数据、训练代码、训练好的模型都在里面。

## 目录

```
01_网页系统/
    交通拥堵预测系统.html     页面（HTML + CSS + JS，未压缩）
    prediction_data.js        预测结果数据，页面靠它显示数字
03_数据/
    清洗后数据.csv            逐小时断面记录，65.2 万条
04_模型代码/
    整体规律模型.py           训练脚本，跑一遍会重新生成模型和网页数据
    models/整体规律模型.pkl   训练好的模型（回归 + 分类 + 校准三个对象）
requirements.txt              依赖版本
```

网页那两个文件必须放在同一目录，双击 html 即可打开，不需要联网。

## 环境

Python 3.9 以上，`pip install -r requirements.txt`。实际用到的版本：

| 包 | 版本 |
|---|---|
| scikit-learn | 1.6.1 |
| pandas | 2.3.3 |
| numpy | 2.0.2 |
| joblib | 1.5.3 |

**注意**：`.pkl` 是 pickle 文件，scikit-learn 版本不一致会加载报错。遇到这种问题直接跑训练脚本重训，不要折腾版本。

## 跑一遍

```bash
# 用包里的数据重新训练 + 重新生成网页数据
python3 04_模型代码/整体规律模型.py

# 本地预览（两个文件才是一个完整页面，别只开 html）
cd 01_网页系统 && python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/交通拥堵预测系统.html
```

训练脚本按相对路径找 `../03_数据/` 和 `../01_网页系统/`，路径以脚本自身位置为基准，在哪个目录下执行都可以。

## 在网页里导入数据

页面自带导入面板，上传 CSV 就能用新数据重训并刷新网页：

```bash
python3 01_网页系统/服务.py
# 浏览器打开 http://localhost:8000
```

页面下方「导入数据 · 重新训练」→ 选择 CSV → 开始训练。服务流程：

1. 校验列名与取值范围（少于 200 行、`lane_count` 不在 1~8 会直接报错）；
2. 调用 `04_模型代码/整体规律模型.py --data <上传文件>` 重新训练；
3. 训练成功后替换 `models/整体规律模型.pkl` 和 `01_网页系统/prediction_data.js`，原文件自动备份成 `.bak`；
4. 页面自动刷新，显示新的模型结果。

直接双击 html 打开时没有后端，导入面板会提示先启动服务。

## 换成自己的数据（命令行）

也可以不走网页，直接用命令行换数据：

```bash
# 换数据
python3 04_模型代码/整体规律模型.py --data /path/to/your.csv

# 同时指定模型和网页数据的输出位置
python3 04_模型代码/整体规律模型.py \
    --data /path/to/your.csv \
    --model-out /path/to/model.pkl \
    --site-out  /path/to/prediction_data.js
```

CSV 必需列（列名大小写不敏感，常见别名会自动对上，如 `flow`→`flow_veh_hour`、`speed`→`avg_speed_kmh`、`lanes`→`lane_count`）：

| 列 | 含义 | 示例 |
|---|---|---|
| `timestamp` | 记录时间 | 2019-01-15 08:00:00 |
| `station_id` | 断面编号（仅用于去重统计，不进模型） | 1010 |
| `flow_veh_hour` | 断面小时流量（辆/h） | 3120 |
| `avg_speed_kmh` | 平均车速（km/h） | 78.4 |
| `occupancy_pct` | 占有率（%） | 14.2 |
| `lane_count` | 车道数 | 3 |
| `weather` | 天气文字 | Clear / Cloudy / Rain / Snow |

可选列：

- `precip_mm`、`snow_cm`：降水量、降雪量，用来把天气分成 6 级；都没有时按天气文字粗分小雨/小雪。
- `is_weekend`、`is_holiday`：缺失时按 `timestamp` 自动推算周末，节假日默认 0。

## 模型在做什么

输入：时段（0–23）、天气（6 级）、日期类型（工作日/周末/节假日）、车道数（2–5）。
输出：拥堵概率 P(车速 < 70 km/h)、每车道流量、平均车速、占有率。

所有断面的记录合在一起学一个通用函数，输入条件就出概率，页面里没有"请选择断面"这种选项。

三个容易踩的点：

1. **天气必须按强度分 6 级**。只分晴/雨/雪时，小雨和暴雨混成一类，效应被平均掉，看起来"天气无关"。
2. **概率要用分类器 + 等温校准**。先回归车速、再用残差分布算概率的做法，在周末和平峰会给出 0%，实际是 9%。
3. **车道数只能当粗代理**。5 车道那档只有 1 个断面、4 车道只有 4 个，"5 车道比 4 车道堵"是路段位置差异，不是因果。
